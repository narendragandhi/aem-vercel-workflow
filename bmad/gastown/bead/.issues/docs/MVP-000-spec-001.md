# MVP-000: User Discovery & Validation

## Overview

Interview AEM developers to validate product assumptions before building.

## Research Questions

1. How do you currently create AEM workflows?
2. How much time per week on XML workflow editing?
3. What's the hardest part of AEM workflows?
4. Would you pay for a visual workflow builder?
5. What would you pay? ($19/$29/$49)
6. Would you try a free beta?

## Target

- 5+ interviews
- 20 beta signups

## Acceptance Criteria

- [ ] 5+ AEM developers interviewed
- [ ] Pain points validated (or invalidated)
- [ ] 20 beta user emails collected
- [ ] Price point tested
